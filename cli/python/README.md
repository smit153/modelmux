# modelmux-cli

Set up, log in to and run [ModelMux](https://github.com/smit153/modelmux)
(AI coding CLIs as a secure, OpenAI-compatible API) with one command.

```bash
pipx install modelmux-cli      # or: uvx modelmux-cli
modelmux up
modelmux login claude
```

Requires Docker (with Compose v2) and Python 3.10+. No other dependencies.
